#Valentino Molinari

#Inicial

Programa que imprime por pantalla la temperatura guardada en una variable int temperatura

Compilación: gcc -Wall -Wextra temperatura.c -o temperatura
Ejecución: ./temperatura

#Fahrenheit

Programa que realiza la conversión de grados celsiu a fahrenheit y muestra la temperatura incial y su conversión por pantalla

Compilación: gcc -Wall -Wextra temperatura.c -o temperatura
Ejecución: ./temperatura

#Classificacio

Programa que analiza si la temperatura inicial es alta o baja, la imprime por pantalla e imprime su clasificación

Compilación: gcc -Wall -Wextra temperatura.c -o temperatura
Ejecución: ./temperatura
